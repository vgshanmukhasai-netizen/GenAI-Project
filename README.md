## Project Abstract

The Terraform-Based AWS Deployment of a Campus AI Assistant aims to develop an intelligent AI-powered assistant that helps college students access academic and campus-related information easily.

The project uses Generative AI to understand student queries and provide relevant responses. AWS cloud services are used to host and manage the application, while Terraform automates cloud infrastructure provisioning using Infrastructure as Code (IaC).

## Problem Statement

Students often face difficulties accessing information about academic schedules, college facilities, events, and other campus-related services.

This project provides a centralized AI-powered assistant that helps students get quick and relevant answers to their campus-related questions.

## Objectives

- Develop an AI-powered campus assistant.
- Deploy the application using AWS cloud services.
- Automate infrastructure provisioning using Terraform.
- Provide secure and scalable cloud deployment.
- Make campus information easily accessible to students.
